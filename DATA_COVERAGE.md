# Data Coverage Summary

## Overview

The `@xinnovations/atlas` package contains comprehensive global location data.

## Statistics

- **Total Countries**: 250
- **Total States/Provinces**: 5,171
- **Coverage**: Worldwide (all continents)

## Country Coverage

The dataset includes all recognized countries and territories:

### Sample Countries (A-Z)

- **A**: Afghanistan, Aland Islands, Albania, Algeria, American Samoa, Andorra, Angola, Anguilla, Antarctica, Antigua And Barbuda
- **B-M**: All countries from Bahamas to Myanmar
- **N-Z**: All countries from Namibia to Zimbabwe

## Data Completeness

Each country includes:

- ✅ Country ID
- ✅ Country Name
- ✅ Currency Code
- ✅ Emoji Flag
- ✅ States/Provinces (where applicable)
- ✅ Cities for each state

## Missing Data

**None!** The dataset is complete with all 250 countries and territories recognized globally.

## Data Quality

- All country names are properly formatted
- Currency codes follow ISO 4217 standard
- Emoji flags are included for visual representation
- States and cities are comprehensively listed

The data is sourced from publicly available geographic databases and has been curated for accuracy and completeness.
